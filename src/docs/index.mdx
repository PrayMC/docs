# 📚 통합 규칙

## 1. 정의

***본 규칙은 공정한 플레이를 위해 존재합니다. 서버에 있는 모든 플레이어는 본 규칙을 적용 받습니다.***

## 2. 커뮤니티

1. **욕설, 비하, 비꼬는 채팅 및 은유적으로 비꼬는 발언**

* 뮤트 1시간 \~ 관리자 재량으로 최대 기간 밴

2. **패드립, 협박성 발언 또는 욕설 필터를 우회하는 행위**

* 뮤트 3시간 \~ 괸리자 재량으로 최대 영구 밴

3. **서로 합의되지 않은 개인정보 언급**

* 기간 밴 \~ 관리자 재량으로 최대 영구 밴

> 관리자 입장에서는 서로 친분이 있어서 언급을 하여도 이를 파악하기 쉽지 않습니다.&#x20;

4. **타인이 보기에 불쾌한 콘텐츠를 게시하는 행위**

* 기간 밴 \~ 관리자 재량으로 최대 영구 밴

## 3. 공정한 플레이

1. **버그 사용(엔더펄 글리치를 포함합니다.)**

* 기간 밴

2. **핵, 메크로 및 비정상적인 이득을 취하는 기능을 사용하거나 스크린 쉐어를 회피하는 행위**

* 영구 밴

> 시스템에서 Diagtrack, Sysmain, DPS, Pcasvc 서비스들을 비활성화 하는 행위는 스크린 쉐어를 진행할때 본인의 결백을  증명하는 과정을 더 힘들게 합니다. 비활성화 하지 마세요.

3. **시스템이 정한 틀에서 벗어난 플레이로 서버에 피해를 주는 행위**

* 영구 밴

3. **처벌을 우회하거나 이를 도와주는 행위**

* 영구 밴

## 4. 인게임&#x20;

1. **다른 플레이어의 정상적인 플레이를 고의적으로 방해하는 행위**

* 기간 밴

2. **다른 플레이어가 규칙에 어긋난 플레이를 하도록 유도하는 행위**

* 기간 밴

팩션이란?

## <mark style="color:orange;">팩션</mark>

팩션은 파벌, 조직, 집단을 의미하는 단어입니다.

&#x20;HCF서버에서 팩션은 하나의 팀이며, 팩션의 팀원을 모아 콘텐츠를 즐길 수 있습니다.

서버에 존재하는 여러 개의 팩션이 우승을 차지하기 위해 서로 경쟁합니다.

대부분의 콘텐츠들이 팩션에 속해 있다는 기준에 만들어져 팩션에 속하는 게 필수입니다.

HCF서버에는 /spawn, /home, /warp 등등의 편의성 명령어가 대부분 존재하지 않기 때문에 어디를 이동하거나 행동을 취할 때 팩션에 속한 팀원들과 함께 움직이는 게 중요합니다.

## <mark style="color:red;">레이다블</mark>

팩션의 DTR 이라는 숫자는 해당 팩션에 가입된 인원수에 비례하여 증가합니다.

팩션의 플레이어가 한번 사망할 때 마다 해당 팩션의 DTR은 1씩 줄어듭니다.

DTR은 줄어든 시점에서 30분이 지나면 다시 원래 숫자로 되돌아옵니다. 이것을 리젠이라고 합니다.

DTR이 리젠중인 상황에는(플레이어가 죽은  시점으로 30분) 다른   플레이어의 팩션 초대는 제한됩니다.

만약 DTR이 0 이거나 음수가 된다면, 해당 팩션 영역에 적용된 모든 보호가 해제됩니다. 즉, 안전했던 베이스는 순식간에 다른 플레이어들에게 약탈을당하거나 습격 당할 수상있는 상태가되는데, 이 상태를 레이드 (Raid)와 할수있다 (able) 라는 단어를 합쳐 <mark style="color:red;">**레이다블 (Raidable)**</mark>이라고 부릅니다.

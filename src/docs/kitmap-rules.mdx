# 킷맵 규칙

## 1. 정의

***본 규칙은 공정한 플레이를 위해 존재합니다. 킷맵을 플레이하는 모든 플레이어는 본 규칙을 적용 받습니다.***

## 2. 원활한 플레이

1. &#x20;**합의되지 않은 상태에서 본인과 다른 킷을 공격하는 행위**

* 경고

2. **스폰 앞에서 특정 플에이어가 거부 의사를 밝혔음에도 지속적으로 죽이려 하는 행위**

* 뮤트 3시간 \~ 괸리자 재량으로 최대 영구 밴
